# web3-bs 文档中心

web3-bs 为 DApp 提供可组合的登录与授权协议，不规定唯一登录方式。

## 文档结构

- [快速开始](./快速开始.md)
- [登录认证](./登录认证/)
- [身份授权](./身份授权/)
- [服务端验证](./服务端验证/)
- [方案调研](./方案调研/)
- [接口参考](./接口参考/)

只需地址控制权使用 SIWE；需要身份资料使用 Wallet Identity；需要资源能力授权使用 UCAN；无插件使用 Passkey。协议可组合但不互相替代。

插件环境的钱包身份登录见[钱包身份登录接入](./身份授权/钱包身份登录接入.md)，没有 Wallet 插件时见[无插件身份登录接入](./身份授权/无插件身份登录接入.md)。

钱包身份认证器按用途拆分：Passkey 的注册、管理和登录边界见[通行证接入](./身份授权/通行证接入.md)；敏感操作的时间型验证码见[TOTP 验证接入](./身份授权/TOTP验证接入.md)。
